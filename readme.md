# LuyệnĐề THPT

Web application hỗ trợ học sinh tải lên đề thi (PDF/Ảnh), tự động bóc tách cấu trúc chuẩn kỳ thi tốt nghiệp THPT, làm bài với giao diện chia đôi, chấm điểm tự động, cung cấp lời giải 2 tab (Tự luận / Trắc nghiệm nhanh) và trợ lý AI giải đáp.

## Công nghệ sử dụng

- **Frontend:** HTML, CSS, JavaScript thuần, MathJax, PDF.js
- **Backend:** Vercel Serverless Functions (`api/`)
- **Database & Auth:** Firebase (Firestore, Auth, Storage)
- **AI:** Google Gemini API
